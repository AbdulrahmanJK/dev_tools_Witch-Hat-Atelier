# Grimoire: работа с интерфейсом

## Карта

**Вся карта** помещает проект на экран. Приближайте область колесом мыши или найдите компонент через поиск. Нажмите печать, чтобы открыть инспектор, исходник и связи.

## Арт-режим и знаки

**Арт-режим** показывает рукописные печати. Знаки отражают конструкции исходника: например, три `useEffect` добавляют три знака на ободе. Внутренние символы состояния и эффектов объединяют группы. У плотных печатей есть два кольца; часть деталей может быть скрыта — список смотрите в инспекторе.

## DevTools

Фильтры выделяют циклы, кандидатов в мёртвый код и другие находки. **Показать сводку** раскрывает счётчики. Для runtime выберите **Runtime и библиотеки**, подключите приложение и запустите показанную команду `dev:grimoire`.

Нажмите **Начать запись**, выполните действие и нажмите **Остановить и сохранить**. Выберите событие для просмотра длительности, дерева и изменений. **Не найдено** означает отсутствие сопоставления с печатью; **Отброшено из буфера** — неполную запись. Обновление родителя само по себе не доказывает причину ререндера.

## Лёгкая карта

Отключите **Подробную карту**, чтобы убрать мелкие знаки и анимации. Навигация и инспектор останутся доступны.
