## 1. О чём проект (Концепция и Лор)

**Grimoire** — это архитектурный визуализатор и DevTools-аудитор кодовых баз (React, Vue, TypeScript/JavaScript) в аутентичной стилистике манускриптов манги Камомэ Сирахамы **«Ателье колдовских колпаков» (Witch Hat Atelier / とんがり帽子のアトリエ)**.

### Философия: «Код как магическая печать Сирахамы»
* **Файлы и компоненты** — это замкнутые рунические круги (**Boundary Rings**), где радиус печати зависит от веса компонента (LOC, хуки, сложность).
* **Хуки и жизненный цикл** — это замковые камни на ободе печати (**Radial Keystones**):
  * `useEffect` / циклы ➔ *Repetition* (Руна Повторения)
  * `useState` / `useReducer` ➔ *Diamond / Strengthen* (Руна Границ и Укрепления)
  * `useSelector` / `useContext` ➔ *Pull* (Руна Притяжения)
  * `useMemo` / `useCallback` ➔ *Convergence* (Руна Схождения / Фокуса)
  * `useHistory` / `useNavigate` ➔ *Direction* (Руна Воздушного Коридора)
* **Потоки данных и импорты** — каллиграфические нити туши (**Ink Threads**) с направляющими стрелами.
* **Архипелаги (Archipelagos / Clusters)** — смысловые папки проекта (`Province: Pages`, `Atelier: UI Components`, `Veins of Power: State/Redux`, `Astral Gateways: API`).

## 2. Незыблемые правила проекта (Правила разработки)

1. **Строго монорепозиторий на `pnpm workspaces`:**
   * Пакеты строго изолированы: `@wha/core`, `@wha/canvas-engine`, `@wha/web`, `@wha/cli`, `@wha/vscode-extension`.
2. **Zero CPU Idle & Разделение рендеров:**
   * Canvas 2D и WebGL работают по принципу умного RAF-цикла с `dirty flag`.
   * Когда холст в покое (нет движения камеры и активной анимации) — потребление процессора **0%**.
   * Изменения в React UI (инспектор, кнопки) **никогда** не вызывают ререндер холста напрямую.
3. **Single WebGL Context Principle:**
   * В приложении существует **строго 1 прозрачный WebGL-холст** (`#grimoire-vfx-canvas`), лежащий между фоном и 2D-текстом. Запрещено создавать отдельные WebGL-контексты на каждый кружок (требование лимитов VS Code Webview).
   * Все эффекты рисуются батчем за **1 Draw Call** через инстансинг (`gl.drawArraysInstanced`).
4. **Коммиты в Git:**
   * Делать коммиты в git **ТОЛЬКО по прямой явной просьбе пользователя**.
5. **Чистый код:**
   * Строгий TypeScript, отсутствие неиспользуемых переменных, отсутствие `any`, проверка через `pnpm run build && pnpm run typecheck && pnpm test`.

## 3. Где мы остановились и статус этапов

### Общий план проекта:
* [x] **Этап 0: Рефакторинг в Монорепозиторий (React 19 + TypeScript + Vite + pnpm)**.
* [x] **Этап 1: Режим по умолчанию (Геометрия «Радиальный Гримуар от Ядра» + Очистка связей)**.
  * Устранена пустая дыра в центре.
  * Двухуровневая сотовая упаковка (Honeycomb Tiers) и центростремительная гравитация: высота проекта сжата с 8200px до 4700px.
  * Воздушная карта: гарантированный зазор 95px между архипелагами.
  * Устранена паутина «спагетти»: на общем плане видны только магистрали; при клике/наведении вспыхивают связи выбранного узла.
* [x] **Этап 1.5: Кинематографичный огонь перегрузки (Anime Sakuga Fire Vortex на WebGL)**.
  * Настоящий аниме-вихрь пламени по референсу (Dual Crescent Waves с раскалённой белой жилой и каплевидными прорезями).
  * Текст и цифры защищены картографическим ореолом (`parchment halo`) и всегда на 100% читаемы поверх огня.
  * **Вариант В:** Для невыбранных (полупрозрачных 20%) кругов огонь заменён на тонкую тлеющую нить рунических углей (1px).
  * Двойной клик в пустой области сбрасывает фильтры в `All` без сброса зума камеры.
* [ ] **Этап 2: Расширенный DevTools Аудит (Мы находимся ЗДЕСЬ)**.
  * [x] **Шаг 1: Циклические зависимости (Петли Уробороса) и Мёртвый код (Забытые свитки)** — **РЕАЛИЗОВАНО!**
    * Алгоритм DFS-бэктрекинга находит циклы (в `upline_admin-module` найдено 3 петли).
    * Алгоритм Knip-анализа находит мёртвый код с 0 входящих импортов (найдено 9 файлов на 992 LOC).
    * Интерактивная подсветка фиолетовых петель арканы (`#a82adb`) и пепельно-серых мёртвых кругов.
    * Быстрые фильтры в шапке: `All`, `🔄 Cycles (3)`, `🍂 Dead Code (9)`, `⚡ Hot (22)`.
    * Умный авто-зум: при нажатии на фильтр камера плавно подлетает так, чтобы в кадр комфортно поместились все целевые узлы.
    * При фильтрах `Cycles` и `Dead Code` огонь выключается, чтобы не шуметь.
    * Кликабельные хлебные крошки петли в Инспекторе для перехода по циклу.
  * [ ] **Шаг 2: Глубокий анализ ререндеров и пропсов (Prop Diff & Re-render Hotspots)** — *СЛЕДУЮЩИЙ ШАГ*.
    * Локализация конкретных немемоизированных пропсов-виновников (`onChange`, `filters`, `columns`) с номерами строк.
    * Советы по мемоизации и выравниванию ссылочной стабильности.
  * [ ] **Шаг 3: Валидация слоёв архитектуры (Architecture Linter / Закон Пакта)**.
    * Выявление запретных связей (например, импорт страниц `Provinces` из изолированных компонентов `Atelier`).
* [ ] **Этап 3: Режим «Unified Grand Seal» (Сакральная Мандала Аполлония — акцент на искусство)**.

## 4. Текущая структура кодовой базы

```
code_viwer_Witch Hat Atelier/
├── bin/
│   └── wha-viewer.js               # CLI-запуск для любого локального проекта
├── packages/
│   ├── core/                       # Ядро: AST-сканер, метрики, раскладка
│   │   ├── src/layout/             # ClusterLayout (Радиальный Гримуар, Centripetal Packing)
│   │   ├── src/scanner/            # GraphBuilder, Detector, Metrics (AST, Cycles, Orphans)
│   │   └── src/types/              # Интерфейсы GrimoireGraph, SealNode, Diagnostics
│   ├── canvas-engine/              # Движок рендеринга
│   │   ├── src/camera/             # Camera (Pan, Zoom, Ease-out Animations, FitBounds, DblClick)
│   │   ├── src/glyphs/             # GlyphRenderer (26 векторных рун Сирахамы, ореолы текста)
│   │   ├── src/renderer/           # WorldRenderer (Синхронизация 2D и WebGL, LOD-фильтрация)
│   │   └── src/vfx/                # WebGL VFXEngine & SakugaFirePass (Anime Flame Shader)
│   ├── web/                        # UI-оболочка
│   │   ├── src/components/         # Header (Фильтры аудита), InspectorDrawer, WhaCanvas
│   │   └── src/store/              # useGrimoireStore (Zustand: режимы, фильтры, навигация)
│   └── cli/                        # Локальный HTTP + SSE live reload сервер
```
