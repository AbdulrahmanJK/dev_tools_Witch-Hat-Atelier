## 1. СУТЬ ИДЕИ (PROJECT CORE CONCEPT)

Создан и развивается **«Witch Hat Atelier Codebase Viewer» (Архитектурный Гримуар)**.  
Это локальный автономный веб-инструмент (Zero-Cloud / Offline) для разработчиков на стеке **React / TypeScript / JavaScript**, который визуализирует любую кодовую базу как **интерактивную карту магических печатей (перо, чернила, пергамент)** по каноническим законам манги Камомэ Сирахамы **«Ателье колдовских колпаков»** (*Witch Hat Atelier* / *Tongari Boushi no Atorie*).

Вместо скучных прямоугольных блок-схем или графов зависимостей:
1. Каждый **React-компонент** — это **многослойная круглая печать (Compound Seal)**.
2. В центре печати расположен **Стихийный Сигил (Core Sigil)**, отражающий природу состояния компонента.
3. Внутри материнского круга вписаны **под-круги кода (Internal Circuit)**: орбита стейта (`useState`), камера жизненного цикла (`useEffect`), малые печати хэндлеров (`handleSubmit`) и вписанные приватные дочерние JSX-компоненты.
4. По ободу вычерчен **пояс знаков-модификаторов (Keystones)**, отражающий реальные операции из AST-дерева (`.map()`, `.filter()`, `Array`, `Set`, `Map`, `loops`, `async/await`). Размеры знаков пропорциональны сложности операций (LOC).
5. Разработчик исследует свой проект на **бесконечном холсте (Infinite Canvas в стиле Figma)** с плавным зумом, панорамированием, интерактивным Свитком Инспектора и горячими клавишами.

## 2. КАНОНИЧЕСКИЙ МАППИНГ: КОД $\rightarrow$ СИМВОЛЫ WHA

### А. Стихийные Сигилы в центре (Core Sigils)
* **Огонь (Fire)** $\rightarrow$ Мутации данных, формы, вызовы `dispatch()`, триггеры экшенов. *(Вектор: треугольник вершиной вверх с вертикальным стеблем-ножкой)*.
* **Вода (Water)** $\rightarrow$ Потоки данных, стриминг, `useSelector`, Redux sagas, REST API, WebSocket/SignalR. *(Вектор: синусоидальный хребет с ребрами)*.
* **Свет (Light)** $\rightarrow$ Чистый UI, визуальная презентация, локальный `useState`, тултипы, модалки. *(Вектор: 8-лучевой ромб)*.
* **Ветер (Wind)** $\rightarrow$ Маршрутизация, навигация, переходы по страницам (`useHistory`, `useLocation`, `useParams`). *(Вектор: S-образный шеврон или двойная ракушка Wind Underfoot)*.
* **Земля (Earth)** $\rightarrow$ Неизменяемые структуры, схемы, конфигурации, таблицы, мемоизация (`useMemo`). *(Вектор: треугольник вершиной вниз с перекладиной)*.
* **Аркана (Arcane)** $\rightarrow$ Корневой хаб (`App.jsx`), провайдеры контекстов.

### Б. Знаки операций на ободе (Keystones)
* `.map()` $\rightarrow$ **Дисперсия (Dispersion ◡ + │)**: рассеивание данных по элементам.
* `.filter()` / `.reduce()` $\rightarrow$ **Концентрация (Convergence ▽)**: сужение и свёртка потока в точку.
* `for`, `while`, `.forEach()`, `useEffect` $\rightarrow$ **Повторение (Repetition ◎)**: цикличность времени.
* `useRef`, вспомогательные функции $\rightarrow$ **Колонна (Column ┴)**: направленный луч вычисления / прямой доступ.
* `async` / `await` $\rightarrow$ **Молния (Bolt ⚡)**: импульс асинхронного прерывания.
* Входные `props` $\rightarrow$ Компасные засечки на внешнем контуре.

### В. Структуры данных и коллекции (Канон сосудов WHA)
* Массивы (`[ ]`) $\rightarrow$ **Сбор (Collection ⋓)**: стягивание разрозненных частиц материи в линию.
* `new Set()` $\rightarrow$ **Сосуд (Orb ○)**: изолированная сфера уникальных сущностей без дубликатов.
* `new Map()` / Словари $\rightarrow$ **Область / Сетка (Region □)**: координатная сетка ключ-значение.

### Г. Геометрия Классов vs Функций
* **ES6 / React Class Component** $\rightarrow$ **Граненая геометрия Strengthen (⬡)**: жесткий шестиугольник с треугольниками Strengthen на вершинах.
* **Функциональные компоненты** $\rightarrow$ Идеальные каллиграфические окружности.

## 3. РЕЖИМЫ ОТОБРАЖЕНИЯ (DISPLAY MODES)

Система поддерживает 3 взаимодополняющих режима:

### 1. Интерактивный режим по умолчанию (Default Interactive Grimoire)
* Все круги цветные, яркие и сочные.
* Внутренние под-круги стейта и функций упакованы внутри центральной камеры.
* **Плавная анимация 60 FPS активна ТОЛЬКО для выделенного узла** (бегущие золотые нити родословной). Без выделения холст находится в режиме **0% CPU (On-Demand Dirty Rendering)**, чтобы ноутбук не нагревался.
* При наведении на неподсвеченный узел всплывает плавающий тултип (`✦ Name (LOC) • Element`).
* При клике справа раскрывается Свиток Инспектора с полным деревом переходов от истока `App` до младших листьев.

### 2. Режим Единого Рисунка (◎ Unified Seal)
* Вся 40 000+ строчная кодовая база проекта собирается в **ОДИН единый великий круг (`App.jsx`)**.
* Внутри круга действует **Секторальная Мандала**:
  * **Север:** Каркас и навигация (`Header`, `Menu`, `Crumbs`);
  * **Восток:** Товары и коммерция (`Products`, `Orders`);
  * **Юг:** Логистика и ревизия (`Reports`, `Consignments`, `Checkup`);
  * **Запад:** Пользователи и настройки (`Auth`, `Users`, `Settings`);
  * **Внешний пояс:** Переиспользуемые Кузницы (`Table`, `Alert`, `Loader`).
* **Топология Кузниц (Shared Atelier Hubs):** если компонент переиспользуется множеством страниц, он масштабируется крупнее страниц, которые его вызывают!

### 3. Режим чистого чертежа (✦ Realistic Art Mode)
* Превращает холст в **монохромную гравюру тушью на чертежной бумаге** (стиль оригинальных страниц манги).
* Полностью скрываются все соединительные паутины и линии импортов.
* Текст внутри под-кругов убирается — остаются только чистые каллиграфические микро-сигилы.
* Интерактивность и тултипы отключаются — холст становится картиной.

## 4. СТРОГИЕ ПРАВИЛА ГЕОМЕТРИИ И ЧИСТОТЫ (CRITICAL INVARIANTS)

1. **Никаких вылетов за пределы круга:**
   Все координаты под-кругов и пояса знаков задаются строго через **пропорции от текущего радиуса $R$**:
   * Пояс внешних знаков: $R_{\text{keystones}} = R \times 0.81$;
   * Разделитель камеры: $R_{\text{chamber}} = R \times 0.64$;
   * Орбита функций и стейта: $R_{\text{sub}} = R \times 0.40$.
   Ни один знак не должен выступать за внешний контур независимо от масштаба!
2. **Только читаемый текст:**
   Категорически запрещено подключать шрифты, заменяющие латиницу на вымышленные руны. Текст должен оставаться на 100% читаемым (*Palatino / Georgia*).
3. **Энергоэффективность Mac (0% Idle CPU):**
   Никаких бесконечных циклов `requestAnimationFrame`. Следующий кадр запрашивается только через `requestRender()` при событиях мыши, зума или при наличии активной анимации выделенного узла.
4. **Защита выделения при перетаскивании (Pan Lock):**
   Перемещение камеры с зажатой кнопкой мыши (более 5px) никогда не должно сбрасывать или переключать выбранный узел.
